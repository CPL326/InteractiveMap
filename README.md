# Interactive Map Editor

A local-first interactive map editor.

## Features

- Upload map
- Create marker
- Edit marker
- Delete marker
- Search
- Filter
- Export / Import project
- Upload custom map images
- Add, edit, delete, and drag custom markers
- Show map coordinates while moving the mouse
- Save collected marker progress locally
- Import and export save data

## Future Plans

- Custom marker types
- Custom icons
- Cloud sync
- OCR integration
